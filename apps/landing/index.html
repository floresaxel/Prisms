Why Prisms

Built like infrastructure, not a subscription.

Offline-first, instantly

Every action commits to a local store in milliseconds and syncs when you’re back. Planes, basements, focus mode — nothing blocks.

Two devices, one truth

Deterministic merges converge every device to the same state — edit the same task on your phone and laptop and lose nothing.

Yours to host

One docker compose up on your own hardware. Your goals, journal and time data never live on someone else’s cloud.

Web · desktop · mobile

A fast web app, a native desktop shell and a mobile client share one data layer — pick up exactly where you left off.

Portable by design

Encrypted one-file backup and restore, and a journal that exports to per-day Markdown. Leaving is easy — that’s the point.

Nothing happens silently

Automations, sync conflicts and rejections land in a review inbox with full provenance. Trust the system because you can audit it.

Get started

Run it tonight.

Prisms is open and self-hosted. One compose file brings up the database, sync service, API and app — it runs happily on very small hardware.

$ git clone https://github.com/floresaxel/Prisms && cd Prisms
$ cp .env.example .env   # fill in your secrets
$ docker compose -f docker-compose.prod.yml up -d --build
