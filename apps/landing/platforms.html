The clients

Pick a screen. It’s all the same brain.

Web

The full feature surface — flowcharts, Gantt, editors, dashboards — as an installable PWA. Your data lives in the browser’s local store, so it opens instantly and works offline.

  • Installable, offline-capable PWA
  • Every view: graphs, boards, agenda, journal

Desktop

A lightweight native shell around the same fast core, with OS notifications. No Electron bloat — it starts fast and stays out of your way.

  • Native window & notifications (Tauri)
  • Identical to web — zero re-learning

Mobile

The day-to-day loop in your pocket: lists, agenda, kanban, timer and habits, with local notifications — plus read-only project graphs for context on the go.

  • Capture, check off, clock in from anywhere
  • Local notifications for blocks & habits

Under the hood

Sync you can reason about.

Instant local writes

Every action commits to the device store first and uploads as a signed command — the UI never waits on the network.

Deterministic merges

Concurrent edits merge per field with a hybrid logical clock; time entries union instead of overwriting. Same inputs, same result, every device.

Conflicts become items

Anything that can’t merge cleanly turns into a review-inbox item on every client — visible, auditable, resolvable. Never a silent overwrite.
