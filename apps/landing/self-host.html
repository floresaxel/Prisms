Self-host

Your goals. Your box.

Prisms is open and self-hosted by design. No accounts you don’t own, no cloud you don’t control — the whole stack comes up with one compose file and runs happily on very small hardware.

1Clone

Grab the repository — everything ships in one place, including the production compose file.

2Configure

Copy .env.example to .env and fill in your secrets. That’s the whole configuration story.

3Compose up

One command builds and starts the database, sync service, API and web bundle.

$ git clone https://github.com/floresaxel/Prisms && cd Prisms
$ cp .env.example .env   # fill in your secrets
$ docker compose -f docker-compose.prod.yml up -d --build
Postgres PowerSync API + jobs Web app

It really does run on small hardware. The reference install is a Surface Go tablet running Ubuntu Server, reached over Tailscale HTTPS from every device. No public IP, no domain, no reverse-proxy yoga required.

Trust & exit

Easy to trust, easy to leave.

Locked down by default

  • Sync streams are JWT-scoped per user — clients can’t widen their own access
  • The server owns all trust fields; clients can’t forge ownership or provenance
  • Secrets sit behind a secure-storage adapter on every platform

Portable by design

  • One-file versioned backup & restore, with optional passphrase encryption
  • Journal exports as plain per-day Markdown files
  • Operator-level database backups documented in the self-hosting guide

FAQ

Before you ask.

Do I need a domain or a public IP?

No. Prisms works great on a private network — the reference setup uses Tailscale, which gives every device a secure HTTPS route to your box with zero port-forwarding. A classic domain + reverse proxy works too.

What hardware do I need?

Very little. Postgres, the sync service and the API are all lightweight — an old laptop, a mini PC or a small VPS is plenty. The reference install runs on a Surface Go tablet.

What happens when I’m offline?

Everything keeps working. Changes commit to the device’s local store instantly and upload when connectivity returns; devices converge deterministically, and anything that can’t merge cleanly becomes a visible review item instead of a silent overwrite.

Can I get my data out?

Always. There’s a versioned one-file export (optionally passphrase-encrypted) that restores on any instance, and the journal exports as plain Markdown. Your data outlives the software.
